# CivicIssue Reporter

This is CivicIssue Reporter. A tool that allows the residents of a city and the officials to collaborate and work together to make the city better. 
It features having tracking of how the project is going and also shows the necessary information to the city officials so that they can fix it.
In the dashboard of the residents it shows how much progress has been made on their report and the status, `denied,accepted,in progress`
